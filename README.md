# End to End Azure Data Engineering Project

Este proyecto tiene como objetivo diseñar e implementar un pipeline de ingeniería de datos en Azure, migrando información desde una base de datos SQL Server on-premise hacia una arquitectura moderna en la nube.

El flujo del proyecto abarca todo el ciclo del dato: extracción, ingesta, almacenamiento, transformación y visualización, siguiendo un enfoque end-to-end.

Las tecnologías utilizada son las siguientes:

-   **SQL Server**: base de datos de origen.
-   **Azure Data Factory**: orquestación e ingesta de datos.
-   **Azure Data Lake Storage**: almacenamiento de datos en bruto.
-   **Azure Key Vault**: gestión segura de secretos y credenciales.
-   **Databricks**: transformación y procesamiento de datos.
-   **Power BI**: análisis y visualización de la información.
